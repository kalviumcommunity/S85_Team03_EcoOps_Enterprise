# Software Requirements Specification

## 1. Introduction
STAP provides seller analytics, trust scoring, and business reporting for marketplace teams.

## 2. Functional requirements
- Users can review marketplace KPI cards and trends.
- Users can search and filter the seller directory.
- Users can open seller detail and learn the trust drivers.
- Users can see business insights and risky sellers.
- Users can export reports.

## 3. Non-functional requirements
- Performance for moderate data volumes
- Validation and input handling
- Secure environment configuration
- Clear error states in the UI

## 4. Assumptions
- Data is synthetic but realistic and representative.
- Applications are run locally in a developer environment.
- PostgreSQL is required for persistent storage.
