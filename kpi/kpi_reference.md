# KPI Reference Document

## 1. Monthly Active Users (MAU)

- Definition: Unique customers who made a transaction in the last 30 days.
- Formula: COUNT(DISTINCT customer_id) in the last 30 days.
- Data Source: customer_id, transaction_date
- Target Range: 5,000 - 6,000
- Owner: Product Manager
- Update Frequency: Daily
- Notes: Measures customer activity.

## 2. Revenue per Customer

- Definition: Average revenue generated by each customer.
- Formula: Total Revenue / Unique Customers
- Data Source: amount, customer_id
- Target Range: $90 - $110
- Owner: Finance Manager
- Update Frequency: Daily
- Notes: Measures customer value.

## 3. Churn Rate

- Definition: Percentage of previously active customers who are no longer active.
- Formula: Churned Customers / Previous Active Customers
- Data Source: customer_id, transaction_date
- Target Range: 0% - 5%
- Owner: Customer Success Manager
- Update Frequency: Monthly
- Notes: Lower churn is better.

## 4. Total Revenue

- Definition: Total money earned from transactions.
- Formula: SUM(amount)
- Data Source: amount
- Target Range: $100,000 - $500,000
- Owner: Finance Manager
- Update Frequency: Daily
- Notes: Measures total business revenue.

## 5. Average Transaction Value

- Definition: Average amount earned from one transaction.
- Formula: Total Revenue / Number of Transactions
- Data Source: amount
- Target Range: $50 - $200
- Owner: Sales Manager
- Update Frequency: Daily
- Notes: Measures average transaction size.
